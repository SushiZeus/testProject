🆕 NEW WORKFLOWS (Version 1.4.0)
═══════════════════════════════════════════════════════════════════════════════

DO REVIEW WORKFLOW (Operations):
  1. Shipping Line submits DO
  2. Operations sees "DO Received" badge
  3. Click purple "REVIEW DO" button
  4. Dialog shows DO document and details
  5. Click green "Approve DO" button
  6. Port Charges upload now enabled
  7. "✓ DO Approved" badge shows

DO CHARGES WORKFLOW (Shipping Line → Finance):
  1. After DO submitted, click "Upload DO Charges"
  2. Upload invoice, enter amount
  3. "DO Charges Pending Payment" badge shows
  4. Finance/Cashier clicks blue "DO CHARGES PAID"
  5. "✓ DO Charges Paid" badge shows
  6. Notification sent to Shipping Line

BL NUMBER AUTO-DISPLAY (Shipping Line):
  1. Documentation Officer enters BL info
  2. Shipping Line opens file details
  3. BL info automatically displays in indigo box
  4. Smart message shows if HBL or MBL
  5. Can still add/edit additional details

DECLARATION STATUS UPDATES:
  1. Upload tax documents
  2. Click blue "TAX PAID" → Status changes immediately
  3. [SEA only] Upload wharfage, click "WHARFAGE PAID"
  4. Status shows "TAXES_PAID"
  5. Click "DECLARATION DONE" → File moves to Operations

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

SERVER WON'T START:
  1. Check if Node.js is installed: node --version
  2. Check if npm is installed: npm --version
  3. Install dependencies: npm install
  4. Check if port 5173 is available
  5. Try: npm run dev

CAN'T ACCESS NETWORK URL:
  1. Check if server is running
  2. Check if computer IP is 192.168.0.114: ipconfig
  3. Check firewall settings
  4. Make sure devices are on same network
  5. Try local access first: http://localhost:5173

LOGIN NOT WORKING:
  1. Check username and password match exactly
  2. Usernames are case-sensitive
  3. Clear browser cache
  4. Try different user account
  5. Check browser console for errors (F12)

FEATURES NOT SHOWING:
  1. Hard refresh browser: Ctrl + F5
  2. Clear browser cache
  3. Check user role has access to feature
  4. Restart server
  5. Check file status is correct for feature
