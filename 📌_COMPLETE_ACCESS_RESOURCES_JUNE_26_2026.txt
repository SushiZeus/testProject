🔧 TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: Server won't start
SOLUTION:
  ✓ Use CMD (Command Prompt), NOT PowerShell!
  ✓ Check if port 5173 is already in use
  ✓ Run: netstat -ano | findstr :5173
  ✓ Close other instances and try again
  ✓ Restart computer if needed

PROBLEM: Can't see changes after update
SOLUTION:
  ✓ Hard refresh browser: Ctrl + Shift + R
  ✓ Clear browser cache: Ctrl + Shift + Delete
  ✓ Close and restart browser
  ✓ Try incognito/private mode
  ✓ Restart development server

PROBLEM: Can't access from network
SOLUTION:
  ✓ Verify server started with --host flag
  ✓ Check firewall settings (allow port 5173)
  ✓ Confirm IP address: ipconfig (look for IPv4)
  ✓ Make sure devices on same network
  ✓ Try localhost first to verify server running

PROBLEM: Button not showing
SOLUTION:
  ✓ Verify logged in with correct role
  ✓ Check file status is correct
  ✓ Ensure previous workflow steps completed
  ✓ Refresh page (Ctrl + F5)
  ✓ Check browser console for errors (F12)

PROBLEM: Notification not received
SOLUTION:
  ✓ Click bell icon (top right)
  ✓ Refresh the page
  ✓ Check user ID matches expected recipient
  ✓ Verify notification store is working

PROBLEM: DO Payment button not visible
SOLUTION:
  ✓ Verify file is SEA shipment
  ✓ Check status is PERMITS_DONE
  ✓ Logged in as shipping_line_clerk
  ✓ No existing DO payment request on file
  ✓ Refresh page

PROBLEM: Port Charges button disabled
SOLUTION:
  ✓ Check Release Order uploaded (green checkmark)
  ✓ Check DO document received (DO Received badge)
  ✓ BOTH must be present for SEA shipments
  ✓ Hover over button to see tooltip
  ✓ Wait for Shipping Line to submit DO if missing

PROBLEM: Finance can't approve DO payment
SOLUTION:
  ✓ Logged in as finance_manager or cashier
  ✓ DO payment request status is PENDING
  ✓ MARK DO PAID button should be visible
  ✓ Refresh page if not showing

PROBLEM: TypeScript errors after update
SOLUTION:
  ✓ Stop server (Ctrl + C)
  ✓ Delete node_modules: rmdir /s /q node_modules
  ✓ Delete package-lock.json: del package-lock.json
  ✓ Run: npm install
  ✓ Run: npm run dev -- --host
