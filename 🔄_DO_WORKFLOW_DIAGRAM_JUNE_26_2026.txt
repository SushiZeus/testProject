🎨 BUTTON COLOR GUIDE
═══════════════════════════════════════════════════════════════════════════════

🟣 PURPLE BUTTON = REQUEST DO PAYMENT
   Who: Shipping Line Clerk
   When: After PERMITS_DONE
   Action: Opens dialog to request DO payment with invoice

🔵 BLUE BUTTON = MARK DO PAID
   Who: Finance Manager / Cashier
   When: DO payment request pending
   Action: One-click to confirm payment (no dialog)

🟢 GREEN BUTTON = SUBMIT DO
   Who: Shipping Line Clerk
   When: After Finance confirms payment
   Action: Opens dialog to upload DO document

📊 STATUS TRACKING
═══════════════════════════════════════════════════════════════════════════════

File has TWO status tracking mechanisms:

1. FILE STATUS (main workflow status)
   • PERMITS_DONE → (stays same during DO payment)
   • DELIVERY_ORDER_SUBMITTED → (after DO uploaded)
   • RELEASE_ORDER_RECEIVED → (after release order)
   • etc.

2. DO PAYMENT REQUEST STATUS (payment tracking)
   • undefined → (no DO payment request yet)
   • 'PENDING' → (payment requested, waiting for Finance)
   • 'PAID' → (Finance confirmed, can submit DO)
   • 'REJECTED' → (Finance rejected, not implemented yet)

This dual-tracking allows:
  ✓ File status remains stable
  ✓ Payment status tracked separately
  ✓ Multiple payment requests possible if needed
  ✓ Clear audit trail

🔄 COMPARISON: OLD VS NEW
═══════════════════════════════════════════════════════════════════════════════

OLD WORKFLOW (Removed):
  ┌──────────────────────────────────────────────────────────────┐
  │ 1. Upload DO Invoice                                         │
  │    → System changes status to WAITING_FOR_DO_PAYMENT         │
  │                                                              │
  │ 2. Finance (unclear what to do)                              │
  │    → Somehow status changes to DELIVERY_ORDER_PAYMENTS_DONE  │
  │                                                              │
  │ 3. Upload DO Document                                        │
  │    → System changes status to DELIVERY_ORDER_SUBMITTED       │
  └──────────────────────────────────────────────────────────────┘
  
  PROBLEMS:
  ❌ No clear Finance action
  ❌ Status changes confusing
  ❌ Two separate upload dialogs
  ❌ No payment tracking
  ❌ Limited notifications

NEW WORKFLOW (Implemented):
  ┌──────────────────────────────────────────────────────────────┐
  │ 1. REQUEST DO PAYMENT (🟣)                                    │
  │    → Creates payment request with details                    │
  │    → doPaymentRequestStatus = 'PENDING'                      │
  │    → Notifies Ops Manager & Finance                          │
  │                                                              │
  │ 2. MARK DO PAID (🔵)                                          │
  │    → Finance one-click approval                              │
  │    → doPaymentRequestStatus = 'PAID'                         │
  │    → Enables DO submission                                   │
  │    → Notifies Shipping Clerk                                 │
  │                                                              │
  │ 3. SUBMIT DO (🟢)                                             │
  │    → Upload DO document only                                 │
  │    → File status = DELIVERY_ORDER_SUBMITTED                  │
  │    → Notifies Ops Manager & all Operation Clerks             │
  └──────────────────────────────────────────────────────────────┘
  
  BENEFITS:
  ✅ Clear Finance approval button
  ✅ Proper payment status tracking
  ✅ Unified payment request workflow
  ✅ Comprehensive notifications
  ✅ Better UX with color-coded buttons
