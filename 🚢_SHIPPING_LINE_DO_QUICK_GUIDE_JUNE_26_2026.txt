═══════════════════════════════════════════════════════════════════════════════
🔄 COMPLETE WORKFLOW (3 STEPS)
═══════════════════════════════════════════════════════════════════════════════

┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 1: SHIPPING LINE CLERK - REQUEST DO PAYMENT                         │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│ When to do this: After file status is PERMITS_DONE                       │
│                                                                           │
│ 1. Go to Shipping Line module                                            │
│ 2. Find your file in the table                                           │
│ 3. Click "REQUEST DO PAYMENT" (purple button)                            │
│ 4. Fill in the dialog:                                                   │
│    • Amount: Enter DO payment amount                                     │
│    • Currency: Select TZS, USD, or EUR                                   │
│    • Invoice: Click to upload invoice file                               │
│    • Description: Explain what the payment is for                        │
│ 5. Click "Submit DO Payment Request"                                     │
│                                                                           │
│ ✅ Result:                                                                │
│    • Badge shows "DO Payment Pending"                                    │
│    • Notifications sent to Operations Manager and Finance Manager        │
│    • Wait for Finance to confirm payment                                 │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 2: FINANCE MANAGER - CONFIRM DO PAYMENT                             │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│ Who can do this: Finance Manager OR Cashier                              │
│                                                                           │
│ 1. Go to Shipping Line module                                            │
│ 2. Find file with "DO Payment Pending" badge                             │
│ 3. Review payment request details (amount, currency, invoice)            │
│ 4. Click "MARK DO PAID" (blue button)                                    │
│                                                                           │
│ ✅ Result:                                                                │
│    • Payment marked as confirmed                                         │
│    • Notification sent to Shipping Line Clerk                            │
│    • Clerk can now submit DO document                                    │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 3: SHIPPING LINE CLERK - SUBMIT DO DOCUMENT                         │
├───────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│ When to do this: After Finance confirms DO payment                       │
│                                                                           │
│ 1. Go to Shipping Line module                                            │
│ 2. Find your file (payment now confirmed)                                │
│ 3. Click "SUBMIT DO" (green button)                                      │
│ 4. Upload the Delivery Order document                                    │
│ 5. Click "Submit Delivery Order"                                         │
│                                                                           │
│ ✅ Result:                                                                │
│    • DO document uploaded and available                                  │
│    • File status changes to DELIVERY_ORDER_SUBMITTED                     │
│    • Notifications sent to Operations Manager and Operation Clerks       │
│    • DO appears in Operations module                                     │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘

🎨 BUTTON COLORS
═══════════════════════════════════════════════════════════════════════════════

🟣 PURPLE - REQUEST DO PAYMENT
   → Shipping Line Clerk requests funds for DO
   → Opens dialog to enter amount, currency, invoice, description

🔵 BLUE - MARK DO PAID
   → Finance Manager confirms DO payment
   → Single click to approve and enable DO submission

🟢 GREEN - SUBMIT DO
   → Shipping Line Clerk submits DO document
   → Opens dialog to upload DO file

🟡 AMBER BADGE - DO Payment Pending
   → Payment request waiting for Finance approval

🟢 GREEN BADGE - DO Received
   → DO document available in Operations (visible to Operation Clerks)

═══════════════════════════════════════════════════════════════════════════════
📦 OPERATIONS MODULE - PORT CHARGES REQUIREMENT
═══════════════════════════════════════════════════════════════════════════════

⚠️ IMPORTANT CHANGE: Port Charges now requires BOTH documents

BEFORE:
  • Port Charges button available after Release Order only

NOW:
  • Port Charges button requires:
    ✅ Release Order uploaded (by Operation Clerk)
    ✅ DO document received (from Shipping Line)

WHAT THIS MEANS:
  • Operation Clerk uploads Release Order
  • Operation Clerk waits for DO from Shipping Line
  • Once both are available, Port Charges button is enabled
  • Operation Clerk can then upload Port Charges

VISUAL FEEDBACK:
  • Button is disabled (grayed out) if DO not received
  • Tooltip says "Wait for DO from Shipping Line"
  • "DO Received" green badge shows when DO available
  • "View DO" button to download/view the DO

❓ FREQUENTLY ASKED QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: What happened to the old "Upload D.O Invoice" button?
A: Replaced with "REQUEST DO PAYMENT" which combines invoice upload with
   payment request in one step. More efficient workflow!

Q: Why can't I see the Port Charges button?
A: Port Charges now requires BOTH:
   1. Release Order uploaded
   2. DO document received from Shipping Line
   Check that both are present. Button will be disabled (grayed) if missing.

Q: How do I know if Finance confirmed my DO payment?
A: You'll receive a notification and the "SUBMIT DO" green button will appear
   in your file's action column.

Q: Where can Operations see the DO document?
A: In the Operations module, files with DO will show:
   • "DO Received" green badge
   • "View DO" button to download/view the document

Q: Can I request DO payment before PERMITS_DONE?
A: No, the "REQUEST DO PAYMENT" button only appears after the file status
   is PERMITS_DONE. This ensures permits are completed first.

Q: What if Finance rejects my DO payment request?
A: Currently the system marks as PAID or keeps as PENDING. If rejected,
   contact Finance Manager directly to discuss and resubmit.

🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: "REQUEST DO PAYMENT" button not visible
SOLUTION:
  ✓ Check file status is PERMITS_DONE
  ✓ Check you're logged in as Shipping Line Clerk
  ✓ Refresh the page (Ctrl + Shift + R)
  ✓ Check file hasn't already has DO payment request

PROBLEM: Can't upload Port Charges in Operations
SOLUTION:
  ✓ Verify Release Order is uploaded (green checkmark)
  ✓ Verify DO document received from Shipping Line (DO Received badge)
  ✓ Check you're logged in as Operation Clerk or Operations Manager
  ✓ If DO not received, wait for Shipping Line to submit it

PROBLEM: SUBMIT DO button not showing
SOLUTION:
  ✓ Check Finance has confirmed DO payment
  ✓ Look for notification about payment confirmation
  ✓ Refresh the page
  ✓ Check you're logged in as Shipping Line Clerk

PROBLEM: Can't see DO document in Operations
SOLUTION:
  ✓ Check Shipping Line Clerk has submitted DO
  ✓ Look for "DELIVERY_ORDER_SUBMITTED" status
  ✓ Refresh the page
  ✓ Check you're in the correct file

📊 WORKFLOW COMPARISON
═══════════════════════════════════════════════════════════════════════════════

OLD WORKFLOW (Removed):
  1. Shipping Clerk: Upload DO invoice
  2. System: Status → WAITING_FOR_DO_PAYMENT
  3. Finance: (No clear action)
  4. System: Status → DELIVERY_ORDER_PAYMENTS_DONE
  5. Shipping Clerk: Upload DO document

NEW WORKFLOW (Current):
  1. Shipping Clerk: REQUEST DO PAYMENT (amount, invoice, description)
  2. Finance: MARK DO PAID (one click)
  3. Shipping Clerk: SUBMIT DO (upload document)
  4. Operations: See DO, proceed with Port Charges

BENEFITS:
  ✅ Clearer workflow with specific buttons
  ✅ Finance has clear action item
  ✅ Better tracking with doPaymentRequestStatus
  ✅ Comprehensive notifications
  ✅ Operations gate ensures DO received

📝 QUICK TIPS
═══════════════════════════════════════════════════════════════════════════════

1. CONTAINER NUMBERS: Fill these early! They're visible to everyone and
   help track shipments.

2. PAYMENT DESCRIPTION: Be specific in DO payment description. Include
   shipping line name, vessel info, or reference numbers.

3. INVOICE UPLOAD: Make sure invoice is clear and readable. PDF preferred.

4. CHECK NOTIFICATIONS: Click the bell icon (top right) to see all
   notifications about your files.

5. DOWNLOAD DO: Operations team should download DO for reference before
   proceeding with Port Charges.

6. TRACK STATUS: Watch the status badges to know where your file is in
   the workflow.
